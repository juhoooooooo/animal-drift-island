# 动物漂流岛

20 关休闲合并救援小游戏，V0.8。

[在线试玩](https://juhoooooooo.github.io/animal-drift-island/)

- 全新八级手绘遗迹与四种动物，海蓝棋盘、分组目标和独立工具按钮。
- 相邻地块交换，横纵三连升级，地形最高 T7。
- 动物实际到达 T5 以上的带顶遗迹时，同格全部获救，无容量上限；获救后仍留在棋盘上。
- 第 11—20 关同时需要营救和修复，第 20 关需要两座 T7 城邦广场。
- 支持自动保存棋盘和主岛进度，在建设页交付食物、木材换取金币。

无需登录。进度保存在当前浏览器，不会上传到服务器；不同设备或浏览器的进度独立。已有进度可继续使用。

本仓库提供包含全部代码和美术素材的静态单文件试玩页面。

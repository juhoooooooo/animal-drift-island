# 动物漂流岛

20关休闲合并救援小游戏，V0.9海岛风格。

[在线试玩](https://juhoooooooo.github.io/animal-drift-island/)

- 恢复清亮蓝色、圆润扁平卡通的关卡界面。
- 八级地块：深海、浅海、浅滩、沙滩、草地、树林、救援小屋、救援中心。前六级沿用最早的海洋地形，后两级为高级救援设施。
- 相邻地块交换，横纵三连升级，最高T7。
- 保留当前救援规则：动物实际到达T5树林后搭起营地，同格动物全部获救、无容量上限，获救后仍留在棋盘上。
- 第11—20关同时需要营救和建造；T6小屋只有亲自参与同级三连时才能移动，T7中心固定。
- 自动保存棋盘与主岛进度；安排工作、收取产出、交付补给扩建小岛。

无需登录。进度保存在当前浏览器，不会上传到服务器；不同设备或浏览器进度独立。已有进度可以继续使用。

# 动物漂流岛

20关休闲合并救援小游戏，V0.12 关卡体验版。

[在线试玩](https://juhoooooooo.github.io/animal-drift-island/)

- 九级海岛地块：T0深海、T1浅海、T2浮冰、T3浅滩、T4沙滩、T5草地、T6树林、T7救援小屋、T8救援中心。
- 第1关为简单引导，第2–20关采用不同布局，参考救援路线4–13步；结合礁岩绕行、紧急救援、限步与设施建造。
- 动物分散在T0/T1，每格最多一只；升级至T6树林以上后同格全部获救，无容量上限，获救后保留可见。
- 小屋、中心和最高级地块可交换，为周围地块三连让位；T8不继续升级，岩石固定。住户随设施移动。
- 第20关需要接回四只动物并建成两座中心；通关结算提供返回主岛与下一关。
- 主岛建造、工作、产出与补给循环，自动保存棋盘和进度。

60项自动检查通过，20关回放均能通关；手机实测第二关和最终关通关，并验证中途刷新可恢复。已有进行中棋盘保持原样，新开或重试后使用新布局。参考路线并非最短解说明。

# 星际移民计划 · V0.16.1

在原动物漂流岛项目上整体改为星际探索：星球家园、蓝紫星空、九级星球地表、六类Q版宇航员职业、30份队员档案，以及统一的关卡、航线、按钮和结算界面。

最新确认玩法：仅上下左右相邻一格互换，必须形成三连；未匹配弹回，不扣步数或倒计时。三个以上同级地表升一级，空位从上方落下，继续连锁。T6生态穹顶开始同格全部队员获救，仍留在格子上，无容量上限。T7/T8同样必须促成三连才能移动。

开局5×6，无合法交换先提示再逐档扩容，最大9×9；保留原地块与个体。9×9卡死可重开或返回。30关布局与通关路径保留，历史存档兼容。未加入金币、商店、派工或生产。

人物曾因长身和细节过多偏离参考，已重画为约两头身、大圆头盔、简洁五官的六类Q版角色。30位队员的编号和名字独立，职业形象按六类共用。

# 动物漂流岛 · V0.13 / V1.9 规则试玩版

[在线试玩](https://juhoooooooo.github.io/animal-drift-island/) · 30关 · 30种动物图鉴 · 无需登录。

在既有游戏中接入 V1.9 文档和本次确认的规则：单个地块与上下左右相邻地块交换，没有匹配也能移动；横纵至少三个同级地块升一级，空位由上方下落补齐，继续扫描连锁。MATCH 4/5/6 暂不额外生成特殊产物，统一升一级。

地块依次为 T0深海、T1浅海、T2浮冰、T3浅滩、T4沙滩、T5草地、T6树林、T7救援小屋、T8救援中心。T7/T8可以正常移动，T8不继续升级，岩石不可移动。

保留用户确认的 T6 起救援：同格动物全部获救，没有人数上限，获救后留在营地并随地块移动。每次新开关卡，动物各占一个 T0/T1 地块。1–2只标准大小，3只以上每只均为70%，全部绘制；密集地块再点一次可查看全部玩伴。

每关从5行×6列开始。仅真正没有合法移动时，先提示再按5×6→6×6→6×7→7×7→7×8→8×8→8×9→9×9扩容，保留原地块、动物与进度。9×9仍无法移动时提供重开和返回。无匹配交换本身不能触发扩容；普通满盘通常仍有可移动地块。

删除主岛建造、升级、派工、生产、补给、资源和材料奖励。主岛展示获救动物，以及累计救援和首次通关两条进度。图鉴包含30个独立物种、未解锁剪影、介绍与首次救援关卡。通关页可下一关、回主岛或重玩，不提供留在营地入口。

旧永久存档迁移前自动备份原文，保留通关、动物ID和名字。旧棋盘原文保留在原键：5×5增加一列，6×6保留已玩布局；新开或重试始终5×6。不同浏览器、设备及网址各自保存进度。

## 本地运行

```sh
node --test tests/*.test.mjs
node scripts/build.mjs
node scripts/serve.mjs
```

打开 http://localhost:4180/，或直接打开 dist/动物漂流岛.html 离线试玩。单文件已包含运行代码、地块和动物素材。

30关有固定布局、随机种子和通关回放，包含全部30物种；游戏运行时读取 src/levels.js，不随机凑关。离线编排入口为 scripts/author-v19-levels.mjs，旧脚本作为版本历史，不用于本版编排。详细规则和确认依据见 docs/V1.9-核心规则与实现说明.md。

原九级地块和四只动物独立素材保留在 assets/coastal-v10/，新增26只独立透明底SVG在 assets/species-v19/。参考概念图未被切割作为正式素材。
